# Park Access → Pro Sports

A static website that tracks park access in low-income neighborhoods and follows the path
**park access → youth sports participation → professional athletes**, built entirely from public data.

- **Map** (`city.html`): color neighborhoods by any step of the path, overlay parks and pro athletes'
  high schools, click a neighborhood for its full profile. A sortable table view is the keyboard-friendly alternative.
- **Analysis** (`analysis.html`): the path by income group, an interactive scatter plot, and every
  correlation tested, in plain language.
- **Methodology** (`methodology.html`): sources, stand-ins, and caveats.

Cities built so far: **Los Angeles County** (343 neighborhoods) and **Chicago** (77 community areas).

## Run it locally

```bash
python3 -m http.server 8000 -d site
# open http://localhost:8000
```

The site is plain HTML/JS with no build step. Leaflet and Observable Plot load from CDNs.

## Rebuild the data

```bash
python3 -m venv .venv
.venv/bin/pip install -r pipeline/requirements.txt
.venv/bin/python pipeline/build_all.py --city los-angeles
```

No API keys are needed. Downloads are cached in `data_raw/` (git-ignored); delete a cached file to refresh
that source. The first build of a city takes a few minutes. The pipeline runs sanity checks (population
totals, plausible ranges, athletes matched to neighborhoods) and refuses to write output if they fail.

## Add a city

1. Copy `cities/los-angeles.yaml` to `cities/<slug>.yaml` and set the state/county FIPS codes, the
   neighborhood boundary source (`arcgis`, `geojson`, or `tracts`), and the map center.
   If the city is smaller than its county, set `clip_tracts: true` (see `cities/chicago.yaml`).
2. Run `.venv/bin/python pipeline/build_all.py --city <slug>`.

The new city appears in the site's city picker automatically. No frontend changes are needed.

## Data sources

| Step | Source | Notes |
|---|---|---|
| Income, kids by poverty level | Census ACS 5-year (B01003, B19013, B17024), bulk summary files | tract level |
| Population for weighting | 2020 Census blocks via TIGERweb | block interior points |
| Parks + 10-minute walk areas | Trust for Public Land ParkServe® | network-based walk areas |
| Courts & fields | OpenStreetMap (Overpass API) | only those inside public parks |
| Youth sports participation | National Survey of Children's Health 2024–25 microdata | state rate by income bracket, applied to each neighborhood's income mix |
| Pro athletes | Wikidata (NBA, WNBA, NFL, MLB, MLS, NWSL, NHL) | placed at their high school; public/private tagged |

See the Methodology page for the full list of limitations. The key one: these are neighborhood-level
patterns built on stand-ins, not proof that parks cause pro careers.

## Deploy

Publish the `site/` folder to any static host. For GitHub Pages, push the repo and set Pages to serve
from a GitHub Actions workflow that uploads `site/`, or copy `site/` into a `docs/` folder and serve from there.

## Layout

```
cities/      one YAML per city (the only thing you edit to add one)
pipeline/    Python data pipeline (fetch_* modules, build_metrics.py, build_all.py)
site/        the static website; site/data/ is generated by the pipeline
```
